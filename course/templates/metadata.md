# TEMPLATE — metadata

Status TEMPLATE: bukan artefak siap atau bukti kelas. Isi field dari scope nyata; jangan menyalin placeholder sebagai fakta.

## Input

Scope/LO, jenis artefak pada ARTIFACT_SPECS, sumber relevan dan output batch sebelumnya.

## Isi wajib

- artifact_id/source_status immutable
- repo_status/readiness/fulfillment/source_verification/official_alignment
- source_ids/dependencies/integration_refs/validation_records/blockers/delivery_evidence

## Output dan pemeriksaan

Path konkret sesuai baseline; metadata schema V1; outcome/materi/aktivitas/bukti terhubung. Catat PASS/FAIL/UNRUN/NOT_APPLICABLE beserta command/versi. Field resmi tanpa sumber tetap PERLU KONFIRMASI SUMBER. Tidak mengklaim kode diuji dari syntax check atau file hadir.
